# Changelog

All notable changes to PENNY will be documented in this file.

## [0.1.0] - 2026-04-16

### Added
- Core annotation processing pipeline (REWRITE, EXPAND, CUT, TONE, DIALOG, PLOT, PACING, CHARACTER)
- Multi-provider support (Anthropic Claude API + Ollama local models)
- Complexity-based model routing (light/standard/heavy tiers)
- Chapter versioning system with idempotency
- Voice compliance checking
- Project scaffolding wizard
- Per-project configuration via PENNY.md
- Git commit/push integration
- Review note generation
- Activity logging (JSONL)
- Settings UI with collapsible sections
- 9 documentation guides
- 302 unit tests across 15 test files
